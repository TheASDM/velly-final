# Static site (Eleventy)

The Valley of Shadows codex is migrating from Wiki.js to a static site
generated by [Eleventy](https://www.11ty.dev/). This document covers what's
scaffolded so far and how to run it.

## Why

Wiki.js was fighting us on layout (nav drawer slots, theme overrides, Vuetify
CSS) and didn't give us much that we were actually using — page edits were
happening via the repo, not the admin UI. Eleventy reads our existing
markdown directly, builds a static site, and we ship it to Cloudflare Pages
(or similar). No backend, no Postgres, no merge-to-wiki-branch dance.

## What's in place

- **`.eleventy.js`** — Eleventy config. Treats the repo root as input, ignores
  infrastructure folders (`.eleventyignore`), and computes `/en/<path>/` URLs
  so all the existing internal links keep working.
- **`_includes/layouts/page.njk`** — Default page layout. Top bar +
  collapsible sidebar (powered by `images/sitemap.json`, which
  `build_sitemap.py` already generates) + content area, themed with the
  gold/dark Cinzel + Crimson Text + IM Fell English aesthetic.
- **`package.json`** — npm scripts: `dev` runs the local server, `build`
  builds to `_site/`.

## Run locally

You need Node 18+ installed.

```bash
npm install                 # one-time
npm run dev                 # serves at http://localhost:8080
```

Open `http://localhost:8080/en/Venturia/Locations/vallombrosa/` and you'll
see the page rendered with the new layout.

## What's still pending

- **Hero cards.** Character/faction/government pages currently have hero
  cards as inline HTML in the markdown. They'll render as-is, but a cleaner
  long-term move is to put the hero card in a Nunjucks include and have
  pages reference it via frontmatter (e.g. `portrait: character-art/noname.png`).
  Saves ~30 lines of inline HTML per page.
- **The chatbot embed.** The Enzo widget's CSS/JS snippet (currently pasted
  into Wiki.js admin) needs to move into `page.njk` so it loads on every
  page.
- **Search.** Eleventy doesn't ship search; we'll need a client-side index
  (Pagefind is the standard choice).
- **Deployment.** Pick a host (Cloudflare Pages, Netlify, Vercel) and wire
  up auto-deploy on push to `main`. Then flip
  `codex.valleyofshadows.wiki` DNS over.
- **Decommissioning Wiki.js.** Once the static site is live and verified,
  the `dnd_wiki` and `dnd_postgres` containers in `docker-compose.yml` can
  come down. The `wiki` git branch becomes unused.

## Workflow going forward

```bash
# 1. Edit markdown pages anywhere in Venturia/, Articles/, Updates/, etc.
# 2. Rebuild the sidebar tree (only when adding/removing/renaming pages):
python3 build_sitemap.py

# 3. Commit + push. Cloudflare Pages (or whichever host) auto-deploys.
git add -A && git commit -m "..." && git push
```

No more wiki branch merges. No more "force Wiki.js to sync." The repo is
the site.
